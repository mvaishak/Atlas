## Interview questions and human checkpoints

1. **Why does a Track A gain not imply better catalog retrieval?** Answer outline: A ranks the supplied judged pool; B measures retrieving from the catalog under fixed candidate limits. Their candidate sets and paired intervals answer different questions.
2. **Why is hybrid's Track A NDCG interval versus dense inconclusive while Track B recall is higher?** Answer outline: A's hybrid-minus-dense interval crosses zero; B's hybrid-minus-dense Recall@100 interval is positive. This supports a retrieval-candidate gain, not a claim that the reranker ordering improved significantly.
3. **Why is known-exact Recall not full recall?** Answer outline: Only known judged relevant items enter the denominator; unjudged items stay unknown, so a catalog item without a judgment is not treated as irrelevant.
4. **What does exact M3 equality establish?** Answer outline: The frozen BM25 output still matches identities, ranks, scores, groups and A/B metrics on these development queries. It neither validates test performance nor proves dense quality.
5. **What did the CPU/GPU comparison establish?** Answer outline: The saved 4,096-row pilot stayed within declared component/cosine tolerances, and all 32 top-k probes matched membership and order. It does not establish bitwise equality for all inputs or Mac runtime compatibility.
