## Review and learning

The data flow is saved rankings plus protected development judgments → original metrics → aggregate replay → original group bootstrap against frozen M4. Alternatives were to trust aggregate report strings, or rerun full model inference. Saved-ranking replay was chosen because it checks ranking/metric consistency without new model work; it can't verify how the rankings were produced.

Failure cases include modified model bytes, duplicate query/product identities, catalog mismatches, group drift and altered metrics. Hash, identity and recomputation checks detect these. An early audit script assumed C_after contained plain identities; inspection showed scored pairs, and the local audit was corrected before replay. Production code and returned artifacts were unchanged.
